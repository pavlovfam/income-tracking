# Учет доходов

Небольшое веб-приложение для личного учета доходов по годам: аренда квартиры с расходами и налогом,
зарплата, проценты по вкладам, прочие доходы, расчет коммуналки по счетчикам и годовые итоги
в рублях, долларах, тенге и любых добавленных валютах.

## Состав

- `index.html` — всё приложение (сборка не нужна).
- `manifest.json`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — иконка и описание для установки на телефон.
- `sw.js` — хранит копию приложения на устройстве, чтобы оно открывалось без интернета.

## Выгрузка на GitHub Pages

1. Распакуйте архив. Загружать нужно сами файлы, а не папку.
2. На github.com нажмите «+» → New repository, назовите, например, `uchet-dohodov`, выберите Public, создайте.
3. В репозитории: Add file → Upload files, перетащите все файлы (кроме этого README, если не нужен), нажмите Commit changes.
4. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты адрес появится вверху той же страницы: `https://ВАШ-ЛОГИН.github.io/uchet-dohodov/`.

Репозиторий публичный, но в нем только код приложения. Ваши данные в репозиторий не попадают.

## Установка на iPhone

1. Откройте адрес в Safari.
2. Нажмите «Поделиться» → «На экран “Домой”» → «Добавить».
3. Запускайте приложение с иконки на экране.

Важно: данные хранятся в браузере устройства. В Safari и в приложении с иконки они раздельные.
Поэтому сначала установите иконку, потом вводите данные именно в ней. Данные не переносятся
между устройствами, а очистка данных сайта их удаляет. Регулярно делайте резервную копию:
Настройки → «Скачать Excel». Восстановить данные можно там же («Восстановить из файла»)
из файла, который выгрузило само приложение.

## Как считается

- Курсы вводятся в каждой записи как «сколько единиц валюты за 1 $». Все суммы пересчитываются через доллар.
- Расходы по аренде = налог + коммуналка по квитанции + maintenance + прочее − вода и КПУ.
  Электричество и интернет в расходы не входят, по ним ведется только учет оплаты квартирантом.
- Тарифы, сумма за интернет и показания счетчиков за прошлый месяц подставляются из предыдущего месяца
  (в январе из декабря прошлого года), пока вы не введете свои.
- Вода и КПУ в аренде берутся из вкладки «Коммуналка», если не заполнены вручную.

Без интернета: после первого открытия с интернетом приложение открывается и без сети. Обновления приходят при следующем открытии, когда связь есть.

Для кнопки «Скачать Excel» страница подгружает библиотеку SheetJS с cdnjs.cloudflare.com,
шрифты IBM Plex подгружаются с Google Fonts.
